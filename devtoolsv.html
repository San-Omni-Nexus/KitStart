Computer Science Tools

Break into the Cyber World

Discover essential software, programming environments and resources to support your journey in computer science. Find tools alongside practical, step-by-step setup guides.

  • VS Code

    Visual Studio Code is a free, lightweight code editor that works with almost every language, including all the ones here. It colours your code, points out mistakes as you type and has a built-in terminal. Thousands of free extensions let you add support for C++, Python, JavaScript and more.

  • Python

    Python is a beginner-friendly programming language with clear, readable syntax. It’s used for scripting, automation, data analysis, artificial intelligence and web backends. Many universities teach it first, and it pairs well with almost any other tool on this page.
  • C++ Setup

    C++ is a powerful language used in systems software, games, embedded devices and telecoms. Unlike Python, your code must be compiled into a program before it can run, so you need a compiler installed. This setup gives you those tools, along with everything to write, build and run your first C++ programs. It’s a great way to learn how computers really work.

  • Git

    Git is a free, open-source Version Control System (VCS) that helps developers track changes in their code and manage different versions of a project. It allows multiple developers to collaborate on the same project, maintain code history, and revert to previous versions when necessary. Git works alongside platforms like GitHub, which allow developers to host repositories, share code, and collaborate online.

  • GitHub

    GitHub is where you store your Git projects online. It backs up your code, lets you share it with others, and builds a public portfolio of your work.

  • Node.js

    Node.js lets you run JavaScript outside the browser. It is the foundation for modern web development and comes with npm, a huge library of free packages.

  • Java JDK

    The Java Development Kit gives you the compiler and tools to build Java programs. Java is widely taught in universities and used in Android apps and enterprise software.

  • WSL (Linux)

    Windows Subsystem for Linux gives you a real Linux terminal inside Windows. Many developer tools and server environments assume Linux, so learning it early pays off.

  • Jupyter Notebook

    Jupyter lets you write and run Python in small blocks, with results and charts shown right below. Popular for learning, data science and AI work.

3. C++ Setup

C++ is a powerful language used in systems software, games, embedded devices and telecoms. Unlike Python, your code must be compiled into a program before it can run, so you need a compiler installed. This setup gives you those tools, along with everything to write, build and run your first C++ programs. It’s a great way to learn how computers really work.

Tap on the link below to download MSYS2, a compiler for C++;

Download MSYS2

Set-Up Instructions

1. Tap on Download MSYS2.

2. Locate and install msys2-x86_64-20260927.exe.

3. Wait for it to finish downloading and run it from windows.

4. When it finishes, keep “Run MSYS2 now” ticked and click Finish, which opens an MSYS2 terminal.

5. In that terminal, run this command:

pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain

6. Press Y (then Enter) when it asks whether to continue. It will download and install for a few minutes.

7. Open Start Menu and, and search “Edit the system environment variables”.

8. Click Environment Variables, select Path under your user variables, then click Edit.

9. Keep the default install location

10. Click New and add the folder C:\msys64\ucrt64\bin.

11. Click OK on every window to save.

12. Open a new Command Prompt and type g++ --version. If you see a version number, it worked.

13. Open VS Code and open extensions.

14. Search C/C++ and download the version provided and verified by Microsoft.

4. Git

Git is a free, open-source Version Control System (VCS) that helps developers track changes in their code and manage different versions of a project. It allows multiple developers to collaborate on the same project, maintain code history, and revert to previous versions when necessary. Git works alongside platforms like GitHub, which allow developers to host repositories, share code, and collaborate online.

Tap on the link below to install git.

Download Git

Set-Up Instructions

1. Tap on Download Git above.

2. Download the latest stable model recommended for your PC.

3. Open the installed .exe from the downloads folder.

4. Keep the default settings. i.e Click 'Next' throughout and 'Finish' at the end.

5. Open Git Bash from the start menu, if it didnt open after the installation was completed.

6. Check if the git version you installed was installed properly by keying in git --version.

7. Set your name by running git config --global user.name "Your Name".

8. Set your email by running git config --global user.email "you@example.com". Use the same email you will use for your GitHub account.

9. Confirm your settings by running git config --list.

You should see your name and email in the output.

Setting Up Git in VS Code.

10. Create a folder for your project in File Explorer.

11. Open VS Code and go to File, then Open Folder, then select the name of your project folder.

12. Open a terminal by tapping the ' ... ' beside run on the menu bar.

Select Terminal, then New terminal.

13. Turn the folder into a Git project by running 'git init'.

14. Create a file in the opened folder by selecting file, then new file.

Enter a name for the file. It should end in the extension of the language you would be using. Eg. .py for python, .cpp for C++.

15. Add the file to git by running 'git add' in the terminal.

16. Save your first version by running git commit -m "First commit" '

5. GitHub

GitHub is a website that hosts Git projects online. Git runs on your computer and GitHub keeps a copy in the cloud, so your code is backed up, shareable and visible to employers and collaborators. Install Git first (see the Git section above).

Tap on the link below to create a free account;

Create GitHub Account

Set-Up Instructions

1. Tap on Create GitHub Account above and sign up with the same email you used in git config.

2. Verify your email address when GitHub sends you a code.

3. Click the + icon at the top right, then New repository.

4. Enter a repository name, leave it empty (do not add a README), and click Create repository.

5. Copy the repository URL shown on the page.

Connecting your VS Code project to GitHub

6. In the VS Code terminal, inside your project folder, run: git remote add origin YOUR-REPOSITORY-URL

7. Rename your main branch by running: git branch -M main

8. Upload your commits by running: git push -u origin main

9. A browser window opens asking you to sign in to GitHub. Sign in and authorise.

10. Refresh your repository page on GitHub. Your files should now appear.

11. From now on, after saving changes, run: git add . then git commit -m "describe your change" then git push

8. WSL (Linux on Windows)

Windows Subsystem for Linux (WSL) runs a real Linux system, such as Ubuntu, inside Windows without needing a second computer or a complicated dual-boot. It works on Windows 10 (recent versions) and Windows 11. Many tutorials, servers and developer tools assume Linux, so this is very useful for computer science students.

Set-Up Instructions

1. Search "PowerShell" in the Windows search bar, right-click it and choose Run as administrator.

2. Type wsl --install and press Enter.

3. Wait for the download and installation to finish. Ubuntu is installed by default.

4. Restart your computer when asked.

5. After restarting, Ubuntu opens and asks you to create a username and password. Choose them and remember them.

6. To verify, open PowerShell and run wsl --list --verbose. You should see Ubuntu listed.

7. Open Ubuntu from the Start Menu and run: sudo apt update

Using WSL in VS Code

8. In VS Code, open extensions and install "WSL" published by Microsoft.

9. Open your Ubuntu terminal, go to your project folder and type: code .

If virtualization is disabled on your PC, you may need to turn it on in the BIOS settings.

9. Jupyter Notebook

Jupyter Notebook lets you write Python in small blocks called cells and see the output directly underneath. It is widely used for learning Python, data analysis, charts and machine learning. Install Python first (see the Python section above).

Set-Up Instructions

1. Open Command Prompt.

2. Type pip install notebook and press Enter. Wait for the installation to finish.

3. Create or choose a folder for your notebooks, and navigate to it in Command Prompt using cd.

4. Type jupyter notebook and press Enter.

5. Your browser opens the Jupyter dashboard. Click New, then Python 3 (ipykernel).

6. In the first cell type print("Hello, Jupyter!") and press Shift + Enter to run it.

Using Jupyter inside VS Code

7. Open VS Code, go to extensions and install "Jupyter" published by Microsoft.

8. Create a new file ending in .ipynb and select your Python version when asked.
