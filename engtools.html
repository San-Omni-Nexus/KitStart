Engineering Tools

Design, simulate and build

Essential software for circuits, electronics, mechanical design and numerical computing. Each tool has a short description, the official download link and step-by-step setup instructions for Windows.

Installers and website layouts change over time. If a button or menu name differs slightly from what is written here, look for the closest match on your screen.

  • MATLAB

    The standard environment for engineering maths, data analysis, signal processing and control systems, with Simulink for block-diagram simulation.

  • GNU Octave

    A free, open-source alternative to MATLAB. Most basic MATLAB code runs in it unchanged, which makes it perfect if you have no licence.

  • KiCad

    Free electronics design software. Draw circuit schematics, lay out printed circuit boards (PCBs) and preview them in 3D.

  • LTspice

    A free circuit simulator. Test a circuit and see its voltages and currents on a graph before you build anything physical.

  • Arduino IDE

    Write code and upload it to Arduino boards. The easiest way to start with microcontrollers, sensors and small robotics projects.

  • Fusion (Autodesk)

    3D CAD for mechanical design. Model parts, assemble them and prepare them for 3D printing. Free education access is available to students.

1. MATLAB

MATLAB is a numerical computing environment used across all engineering fields for matrix maths, plotting, signal processing, control design and simulation. Simulink, its add-on, lets you build and simulate systems with blocks.

Paid / licence neededWindowsLarge download

Check first whether your university provides a MATLAB licence. If it does, install with your university email. If not, MathWorks offers student and trial options, or you can use GNU Octave below.

MATLAB Download

Set-Up Instructions

  1. Tap on MATLAB Download above.
  2. Click Sign in, or create a MathWorks account using your university email address.
  3. Link your account to a licence (campus licence, student licence or trial) when MathWorks asks.
  4. Download the Windows installer and open it from your downloads folder.
  5. Sign in to your MathWorks account inside the installer and accept the licence agreement. Click Next.
  6. Select the licence you want to use. Click Next.
  7. Keep the default installation folder. Click Next.
  8. Choose products. Keep MATLAB ticked, add Simulink, and tick only the toolboxes you need. You can always add more later.
  9. Click Install and wait. This can take a long time because the files are several gigabytes.
  10. When it finishes, click Finish and open MATLAB from the Start Menu.
  11. To verify: in the Command Window type version and press Enter. A version number means it works.
  12. Try your first line: x = 0:0.1:10; plot(x, sin(x))

2. GNU Octave

GNU Octave is a free numerical computing tool with a MATLAB-compatible language. It is ideal for practising matrix operations, plotting and simple simulations without paying for a licence.

FreeWindows

Octave Download

Set-Up Instructions

  1. Tap on Octave Download above.
  2. Under Windows, choose the installer (.exe) for 64-bit Windows.
  3. Open the downloaded file and click 'Yes' if Windows asks for permission.
  4. Accept the licence, keep the default options and install location. Click Next, then Install.
  5. Click Finish and open Octave from the Start Menu.
  6. To verify: type version in the Command Window and press Enter.

3. KiCad

KiCad is a free, open-source suite for electronics design. It includes a schematic editor to draw circuits, a PCB editor to design boards, and a 3D viewer to see the finished board.

FreeWindows

KiCad Download

Set-Up Instructions

  1. Tap on KiCad Download above.
  2. Choose the latest stable Windows (64-bit) installer from one of the download mirrors.
  3. Open the installer from your downloads folder and click 'Yes' when Windows asks for permission.
  4. Keep the default components and install location. Click Next, then Install.
  5. Wait for the installation to complete, then click Finish.
  6. Open KiCad from the Start Menu. If it asks about library tables or settings on first run, accept the defaults.
  7. Create your first project: File, then New Project, and name it.
  8. Double-click the schematic file (.kicad_sch) to open the Schematic Editor. Press A to add a component.
  9. Open the PCB Editor from the project window when you are ready to lay out a board.

4. LTspice

LTspice is a free, fast circuit simulator from Analog Devices. You draw a circuit, run a simulation and view waveforms for voltage and current, which is great for checking designs before building them.

FreeWindows

LTspice Download

Set-Up Instructions

  1. Tap on LTspice Download above.
  2. Scroll to the Downloads section and choose the Windows version.
  3. Open the downloaded installer and accept the licence agreement.
  4. Keep the default options and install location, then finish the installation.
  5. Open LTspice from the Start Menu.
  6. Start a circuit: File, then New Schematic.
  7. Press F2 to place components such as a voltage source, resistor and capacitor, then wire them up.
  8. Set the simulation type under Simulate, then Configure Analysis (for example Transient).
  9. Click Run (the running-man icon), then click on a wire in the circuit to plot its voltage.

5. Arduino IDE

The Arduino IDE is where you write programs (called sketches) and upload them to Arduino boards. It is the most beginner-friendly route into electronics, sensors, motors and embedded systems.

FreeWindows

Arduino IDE Download

Set-Up Instructions

  1. Tap on Arduino IDE Download above.
  2. Download the Windows installer for Arduino IDE 2.x. You may skip the donation prompt.
  3. Open the installer, accept the licence and keep the default options. Click Install.
  4. If Windows asks to install device drivers, click Install. These let your computer talk to the board.
  5. Open the Arduino IDE and connect your board with a USB cable.
  6. Go to Tools, then Board, and select your board (for example Arduino Uno).
  7. Go to Tools, then Port, and select the port your board is connected to.
  8. Open File, then Examples, then 01.Basics, then Blink.
  9. Click the Upload arrow. When the small LED on the board starts blinking, your setup works.

6. Fusion (Autodesk)

Fusion is a cloud-connected 3D CAD tool for mechanical design. You sketch, model parts, build assemblies and export files for 3D printing or manufacturing. Autodesk offers free education access to eligible students.

Free for studentsWindows

Autodesk Education

Set-Up Instructions

  1. Tap on Autodesk Education above.
  2. Create an Autodesk account, or sign in if you already have one.
  3. Verify that you are a student when asked. Use your university email where possible.
  4. Find Fusion in the list of education software and click Get started.
  5. Download the installer and open it from your downloads folder.
  6. Sign in to your Autodesk account when the installer asks, and let it finish. This takes a few minutes.
  7. Open Fusion from the Start Menu.
  8. Start a first model: click Create Sketch, draw a rectangle, finish the sketch, then use Extrude to make it 3D.
